# Design

Gameplay research and design documents for the physics-based, first-person
superhuman movement game built on this Godot fork (4.8-dev, Jolt physics).

- `reports/Physics based superhuman movement design.md` — the round-one game
  design and technical plan: controller architecture, learning-to-walk
  opening, consequence-gated power ladders, controls, procedural animation and
  camera, destruction options (including the DMM verdict), Houdini pipeline,
  learned versus hand-authored control, phased implementation plan, and a
  bibliography where every claim is traceable.
- `research_notes/Physics based superhuman movement design/` — the thirteen
  research notes the report was synthesized from, one per subtopic. Each
  records cited findings, inferences, gaps, sources that could not be opened,
  and better search terms and venues for follow-up.

The engine claims in both were checked against this repository's source tree
(paths and line numbers are cited inline) on 2026-09-27.
